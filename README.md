# 🔬 Нейросетевой метод синтеза дифракционных оптических элементов (ДОЭ)

Решение задачи хакатона по скоростному синтезу фазовых ДОЭ для одновременного формирования 4-плоскостной 3D-сцены методом дифракции Френеля.

## 🎯 Физические параметры задачи
- **Длина волны лазера**: $\lambda = 532$ нм ($532 \times 10^{-9}$ м)
- **Линейный размер пикселя ПВМС**: $\Delta u = \Delta v = 10$ мкм ($10 \times 10^{-6}$ м)
- **Размер ДОЭ и объектных изображений**: $128 \times 128$ пикселей
- **Фаза ДОЭ**: от $-\pi$ до $+\pi$ (в выходном 8-битном PNG: $-\pi \to 0$, $+\pi \to 255$)
- **4 расстояния восстановления 3D-сцены**:
  - $z_1 = 24.1$ мм
  - $z_2 = 25.3$ мм
  - $z_3 = 26.5$ мм
  - $z_4 = 27.7$ мм
- **Метод оптического расчета**: прямое вычисление дифракции Френеля на основе выражения с одним 2D-преобразованием Фурье (1-FFT)

---

## 🏗️ Архитектура решения

Решение построено на **Physics-Informed Deep Learning** подходе:
1. **Нейросеть (U-Net с Bottleneck и Skip Connections)**:
   - Вход: 4 канала (по одному на каждое из 4 целевых изображений $128 \times 128$).
   - Выход: 1 канал фазы ДОЭ со строгой физической активацией $\tanh \times \pi \in [-\pi, +\pi]$.
   - Время прямого вывода: **~5 миллисекунд** (в сотни раз быстрее классического алгоритма Герчберга–Сэкстона).
2. **Дифференцируемый оптический слой дифракции Френеля**:
   - Реализует прямое волновое распространение через 1-FFT с квадратичными фазовыми ядрами $\exp\left(j \frac{\pi}{\lambda z}(u^2+v^2)\right)$.
   - Сохраняет модули комплексной амплитуды $|K(x, y)|$ строго по требованиям ТЗ.
3. **Оценка метрик**:
   - **SSIM (Индекс структурного сходства)** — основная метрика оценки контуров.
   - **Pearson (Коэффициент корреляции Пирсона)** — оценка корреляции яркости.

## 🐳 Запуск в Docker

Решение полностью автономно и запускается в Docker-контейнере без ручной настройки.

### 1. Сборка Docker-образа
```bash
docker build -t photonics-doe .
```

### 2. Запуск тестирования на комплекте изображений

#### Вариант А: Передача папки с 4 изображениями комплекта
```bash
docker run --rm -v /путь/к/папке_с_картинками:/input -v $(pwd)/output:/output photonics-doe --input_dir /input --out /output
```

#### Вариант Б: Передача 4 файлов напрямую
```bash
docker run --rm -v $(pwd):/data photonics-doe --img1 /data/1.png --img2 /data/2.png --img3 /data/3.png --img4 /data/4.png --out /data/output
```

#### Вариант В: Быстрый тест на встроенном демонстрационном комплекте
```bash
docker run --rm -v $(pwd)/output:/app/output photonics-doe --out /app/output
```

## 💻 Локальный запуск без Docker (через Python)

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск генерации ДОЭ
```bash
# Синтез ДОЭ для 4 картинок:
python run.py --img1 1.png --img2 2.png --img3 3.png --img4 4.png --out output

# Или указав папку с комплектом:
python run.py --input_dir /path/to/test_set --out output

# Мгновенный ультра-быстрый режим чистой нейросети (~5 мс):
python run.py --steps 0 --out output

# Запуск локального веб-интерфейса:
python app.py
```

## 📤 Выходные файлы в папке назначения:
По завершении работы программы в папке `--out` формируются:
- **`doe.png`** — синтезированный фазовый ДОЭ (128×128, 8-бит, Grayscale, где $-\pi \to 0, +\pi \to 255$).
- **`rec_1.png` ... `rec_4.png`** — 4 восстановленных изображения (128×128, 8-бит, Grayscale, модули амплитуды).
- В консоль выводятся значения **SSIM** и **Pearson** для каждого из 4 расстояний, средние значения и точное время работы модели.
